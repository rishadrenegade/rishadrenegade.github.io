# Md Maksudul Haque Rishad · Portfolio

Personal portfolio website for a Computer Engineering student at Texas Tech University, hosted on GitHub Pages at https://rishadrenegade.github.io

## Files
* index.html  : page layout
* style.css   : colors and design
* script.js   : chip tracker, menu, animations, auto loading from folders
* data.js     : ALL YOUR CONTENT (edit this one to update the site)
* images/     : your photo (rishad.jpg) and project images
* bench/      : hardware builds, one folder per build (see HOW-TO-ADD.md)
* apps/, projects/ : new apps and projects show up automatically (see HOW-TO-ADD.md)
* certificates/ : certificate PDFs or images

## Updating
* Resume: not posted publicly; visitors request it on LinkedIn or by email.
* New project: open data.js, copy one project block, change the words, upload a photo to images/ and put its path in images.
